name: use-codex
description: Use as a fallback when needing to consult with GPT models if your harness doesn't natively support GPT subagents.
---

Do not use this skill if the current harness has native GPT subagent capability or `codex` is not set up on this computer.

Otherwise, talk to Codex using `codex exec -m <model> "<prompt>" <other-args>`

Default to GPT 6.2 Sol unless otherwise specified.
